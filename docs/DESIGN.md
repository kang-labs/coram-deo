# 하나님앞에서 — 설계서

교회 훈련 과정(12주)의 주간 체크표 '하나님앞에서'를 종이 대신 폰으로 쓰는 안드로이드 앱.

## 1. 핵심 원칙

- **반·일정표·체크 항목·기록요령은 서버(Firestore)**에 둔다. 관리자가 앱에서 고치면 앱 업데이트 없이 모두에게 보인다. 누구나 읽기, 관리자만 쓰기.
- **개인 체크 기록은 폰에만** 저장한다(`shared_preferences`, 로그인 없음). 다른 사람은 볼 수 없다.
- 로그인은 관리자 모드에서만(구글 로그인, 관리자 이메일만 쓰기 허용).
- 화면에 보이는 항목·종류는 모두 데이터(항목 목록 + 공통 빌더)로 그린다. 반마다 항목이 달라도 코드 수정이 없어야 한다.

## 2. 반 (course)

반 하나 = 한 학기 과정 하나. 처음 등록할 반:

| 반 | 수업 | 한 주 |
|---|---|---|
| 양육A반 | 화 10:00 | 수~화 |
| 양육B,C반 | 토 18:00 | 일~토 |
| 제자학교A반 | 화 10:00 | 수~화 |
| 제자학교B반 | 토 14:00 | 일~토 |
| 제자대학1학기A반 | 목 10:00 | 금~목 |
| 제자대학1학기B반 | 목 20:00 | 금~목 |
| 제자대학2학기 | 토 18:00 | 일~토 |

- **한 주 = 그 주 수업날로 끝나는 7일.** N주차 범위 = (N주 수업 날짜 − 6일) ~ (N주 수업 날짜). 예: 제자대학2학기 6주차(10/17 토) = 10/11(일)~10/17(토).
- 연휴·휴강 주도 주차는 그대로 센다(체크도 한다).
- 오늘이 속한 주차를 자동으로 고른다. 학기 전이면 1주, 끝났으면 마지막 주. 사용자는 다른 주차로 바꿔 볼 수 있다.

## 3. 체크 항목

항목 하나 = 이름 + 칸(part) 1개 이상. 종이 표에서 대각선으로 나뉜 칸(예: 출석/후기)은 칸이 2개, 금요기도회는 3개.

칸 종류(`PartType`):

| 종류 | 입력 | 표에 보이는 값 | 예 |
|---|---|---|---|
| `mark` | ○ / X (다시 누르면 비움) | ○, X | 교재예습, 필독서, 과제, 후기, 셀가족모임 |
| `attend` | ○ / 지 / X | ○, 지, X | 출석 |
| `days` | 7일 체크(요일 칸) | 한 날 수(0~7) | 성경읽기, 큐티, 기도(하루 1시간 = 1) |
| `dawn` | 7일 체크 | 점수: 3회 이상 0, 2회 −1, 1회 −2, 0회 −3 | 새벽기도 |

- 아직 오지 않은 날은 체크할 수 없다.
- 항목 id는 바꾸지 않는다(폰의 기록이 id로 이어짐). 이름·순서는 바꿀 수 있다.

기본 항목(제자대학2학기 종이 표 그대로, 새 반의 기본값):

1. 출석/후기 — 출석(attend) + 후기(mark)
2. 교재예습 (mark)
3. 필독서 읽기 (mark)
4. 성경읽기 (days)
5. 큐티 (days)
6. 기도 (days)
7. 새벽기도 (dawn)
8. 강사 특별과제 (mark)
9. 구절암송 (mark)
10. 월요목회 도고기도 (mark)
11. 금요기도회 — 출석·후기·강단기도 (mark ×3)
12. 축제예배/후기 — 참석(mark) + 후기(mark)
13. 열정예배/후기 — 참석(mark) + 후기(mark)
14. 셀가족모임 (mark)
15. 행복모임 인도 (mark)

## 4. 일정표

주차마다: 날짜, 훈련 내용(여러 줄), 암송구절, 나눔, 휴강 여부. 그 밖에 개강·졸업예배 같은 줄(extras: 이름, 날짜, 내용).

## 5. 기록요령 (반마다 글, 관리자가 수정)

- 출석: 출석(○) 지각(지)로 표기, 결석 3회부터는 과락 처리됩니다. 꼭 반장을 통해 사전 연락하세요.
- 성경: 1일 맥체인 성경읽기(셀라이프 캘린더) 읽은 날짜 기록 / 7일간 다 했을 경우 '7'이라고 표시
- 큐티: <셀라이프> 한 날짜 기록 / 7일간 다 했을 경우 '7'이라고 표시
- 교재예습, 필독서 읽기, 과제, 후기: 했으면(○), 안 했으면(X)로 표시
  - 교재예습: 말씀구절을 손으로 직접 기록합니다(5절 이상의 구절은 첫 구절, 마지막 구절만 기록). 예습하면 더 큰 은혜가 있습니다.
  - 필독서 읽기: 정해진 주에 정해진 분량만큼 읽고 나눔을 준비합니다.
- 축제예배, 셀가족모임, 행복모임, 금요기도회: 참석(○) 불참(X)로 표기
- 기도: 한 시간만큼 기록 / 하루 1시간, 일주일간 7시간 했으면 '7'이라고 표시
- 새벽기도: 주 3회 참석: 0, 2회 참석: −1, 1회 참석: −2, 미참석: −3

## 6. 화면

하단 탭 4개:

1. **이번 주**: 주차 고르기(◀ 6주차 · 10/11~10/17 ▶), 이번 주 일정 카드(훈련 내용·암송구절·나눔), 항목 카드 목록.
   - days/dawn: 요일 7칸(요일 + 날짜), 오늘 칸 강조, 옆에 합계(성경 5/7, 새벽기도 2회 → −1).
   - mark/attend: 칸마다 알약 선택(○ X / ○ 지 X).
2. **체크표**: 종이와 같은 표(주차 × 항목). 가로로 밀어 보기, 첫 열(주차)은 고정. 주차 줄을 누르면 그 주 '이번 주' 화면으로. 반장에게 보여 줄 수 있게.
3. **일정표**: 개강~졸업예배까지 목록, 이번 주 강조, 휴강 주 흐리게.
4. **설정**: 반 바꾸기(기록은 반마다 따로 보관), 내 이름(표 위에 표시), 기록요령 보기, 테마, 관리자 모드.

처음 실행: 반 고르기 → 이번 주 화면.

### 관리자 모드

설정 > 관리자 모드 > 구글 로그인(관리자 이메일만). 반 목록 → 반 추가·복사(새 학기)·숨기기·삭제, 반 편집:
- 기본 정보: 반 이름, 기수·학기 글(예: 22기 2학기), 수업 요일·시간, 순서, 보이기.
- 일정표: 1주 날짜 → 12주 자동 채움(주 수 바꿀 수 있음), 주마다 내용·암송구절·나눔·휴강, 개강·졸업 같은 추가 줄.
- 체크 항목: 추가·삭제·이름·순서·칸 종류. 새 반은 기본 항목으로 시작.
- 기록요령 글.

## 7. 데이터

### Firestore

```
courses/{courseId}
  name: '제자대학2학기'
  term: '22기 2학기'
  weekday: 6            // DateTime.weekday (월1 … 일7), 수업 요일
  time: '18:00'
  order: 7
  visible: true
  weeks: [ {date: '2026-09-12', title: '1과 위대한 부르심', verses: '고후 1:20\n엡 6:10,11', sharing: '', off: false}, … ]   // 순서 = 주차
  extras: [ {label: '개강', date: '2026-09-06', title: 'OT'}, {label: '졸업예배', date: '2026-12-06', title: ''} ]
  items: [ {id: 'attend', label: '출석/후기', parts: [{label: '출석', type: 'attend'}, {label: '후기', type: 'mark'}]}, … ]
  guide: '기록요령 글'
  updatedAt
```

규칙: `courses` 누구나 읽기, 쓰기는 관리자 이메일(`request.auth.token.email`이 목록에 있고 email_verified)만.

### 폰 (shared_preferences)

- `courseId`: 고른 반
- `name`: 내 이름
- `rec.{courseId}`: JSON `{ "6": { "attend": ["o", "o"], "bible": [127], … } }`
  - 주차 → 항목 id → 칸별 값. mark/attend: `"o" | "x" | "late" | null`, days/dawn: 7비트 정수(bit0 = 그 주 첫날).
- 기록은 반마다 따로라 반을 바꿔도 지워지지 않는다.

## 8. 나중에 할 것

- 기록 백업·복원(파일로 내보내기) — 폰에만 저장하므로 폰을 바꿀 때 필요.
- 매일 저녁 체크 알림.
- 체크표 이미지로 저장·공유(반장에게 보내기).
